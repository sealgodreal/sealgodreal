## Deploying Your Own Nebula

> **Requirements:** Python and Git

### Local Setup

Open a terminal, navigate to a directory of your choice, and run:

```bash
# Clone the project
git clone https://github.com/sealgodreal/nebulabrowser.git

# Navigate to the project
cd nebulabrowser
```

#### Swapping the Proxy Link

You can replace the proxy link with your own. Find the `p` (proxy) value in the following files and swap it out:

- `assets/main/n8qvtxr4mkzpa.js`
- `assets/main/n8qvtxr4mkzpa_bo.js`
- `assets/html/cloudeducation.html`
- `assets/html/educationpage.html`
- `assets/html/learningtools.html`

#### Running Locally (for testing)

Run the following in the same terminal you cloned the repo in:

```bash
# Start a local server
python -m http.server 3000

# Open it in your browser
start http://127.0.0.1:3000
```

---

### Public Deployment

Once you've configured everything to your liking, initialize a Git repo and push it to GitHub:

```bash
# Initialize a new Git repository
git init

# Stage all files
git add .

# Commit your changes
git commit -m "Initial commit"

# Add your GitHub repo as the remote (replace the URL with your own)
git remote add origin https://github.com/yourusername/your-repo-name.git

# Push to GitHub
git push -u origin main
```

Then, head over to [Vercel](https://vercel.com) (recommended) and:

1. Log in or sign up
2. Create a new project
3. Connect your GitHub account
4. Select your repository
5. Name your project
6. Click **Deploy**

You should now have your own Nebula link!
